# Hi, I'm Amirhossein Sadeghi

I am a Computer Engineering student at Isfahan University of Technology, building a project portfolio around **Intelligent Physical Systems**.

My main interest is not pure software alone, but the intersection of computation and real-world dynamic systems:

- dynamics and control
- sensing and sensor data
- embedded systems and IoT
- state estimation and filtering
- robotics and cyber-physical systems
- machine learning for monitoring, diagnosis, inspection, and estimation

I am especially interested in systems where software interacts with physical behavior through sensors, models, estimation, and feedback.

## Portfolio Direction

My current portfolio follows this path:

Dynamics → Control → Sensor Data → Filtering / Estimation → Embedded Intelligence → Intelligent Physical Systems

The goal is to build engineering evidence, not only code. I focus on projects that include modeling, simulation, noisy measurements, hardware planning or integration, evaluation plots, and documented engineering decisions.
